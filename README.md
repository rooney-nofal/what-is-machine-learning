# What is Machine Learning? (What the ML)

##  Project Overview
This project is an educational and technical exploration of the fundamental concepts of Artificial Intelligence and Machine Learning. Developed as part of the **La Plateforme** curriculum, this repository serves as both a theoretical reference and a practical code portfolio.

The objective was to deconstruct 12 core terms from the "What the ML" specification, providing not just definitions, but "hands-on" proof of concepts using Python.

##  Methodology: What We Built
For each of the required technical terms, this project follows a strict two-step structure within a Jupyter Notebook environment:

1.  **Theoretical Deep-Dive:**
    * **Definition:** What is the concept professionally?
    * **Application:** Where and why is it used in industries like Finance, Healthcare, and Tech?
    * **Role in AI:** How does it fit into the broader Computer Science ecosystem?

2.  **Practical Implementation (Python & Scikit-Learn):**
    * We translated theory into code by building isolated exercises for each term.
    * We utilized professional libraries (**Pandas, NumPy, Matplotlib, Seaborn**) to generate synthetic datasets.
    * We visualized the results using publication-quality charts (Heatmaps, Regression Lines, Cluster Scatter Plots) to demonstrate the "math in action."

## Key Concepts Covered
The project covers the following technical pillars:
* **A. Data Science:** The lifecycle of extracting insight from noise.
* **B. ML vs. Deep Learning:** Understanding the difference between statistical learning and neural networks.
* **C & D. Learning Paradigms:** Supervised (Labeled) vs. Unsupervised (Discovery-based) Learning.
* **E & F. Classification:** Differentiating between SVM (Support Vector Machines) and K-Means Clustering.
* **G. Regression:** Predictive modeling for continuous data (e.g., Revenue Forecasting).
* **H & I. Validation:** Cross-validation techniques and the critical Train/Test split (80/20 rule).
* **J. Correlation:** Pearson coefficient analysis with Heatmap visualization.
* **K & L. Optimization:** Manual implementation of Cost Functions (MSE) and visualization of Gradient Descent.

##  Technology Stack
* **Language:** Python 3.x
* **Environment:** VS Code, Jupyter Notebook
* **Core Libraries:**
    * `scikit-learn`: For Model building and Validation.
    * `matplotlib` & `seaborn`: For Data Visualization.
    * `pandas`: For Data Management.
    * `numpy`: For Matrix operations and Math.

##  How to Run This Project
1.  **Clone the repository:**
    ```bash
    git clone [https://github.com/Rooney/what-is-machine-learning.git](https://github.com/Rooney/what-is-machine-learning.git)
    cd what-is-machine-learning
    ```

2.  **Set up the Virtual Environment:**
    ```bash
    python -m venv venv
    # Windows:
    .\venv\Scripts\activate
    # Mac/Linux:
    source venv/bin/activate
    ```

3.  **Install Dependencies:**
    ```bash
    pip install jupyter pandas numpy matplotlib seaborn scikit-learn
    ```

4.  **Launch the Notebook:**
    Open `master_ml_project.ipynb` in VS Code or run `jupyter notebook` in your terminal.
